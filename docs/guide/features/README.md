# Features

One page per Browsentic capability: what it does, how you reach it, and where it stops.

If you have not set Browsentic up yet, start with [Install](../install.md), [Pair](../pair.md) and
[First run](../first-run.md).

## Talking to it

| | |
| --- | --- |
| [Conversations](conversations.md) | Typing and dictating, one conversation per tab, the sessions strip, history |
| [Hands-free](hands-free.md) | Talking to the page through a mic you can drag anywhere, with the side panel put away |
| [Instant commands](instant-commands.md) | Commands such as "go back" and "scroll to the top" that run in milliseconds without an agent |
| [A-Eye](a-eye.md) | Pointing at an element instead of describing it, and the agent asking you to point |
| [Action cues](action-cues.md) | A ring on each element the agent is about to click, type into or read |
| [Profile](profile.md) | Your details and standing rules, saved once, so forms get real values instead of guesses |
| [Blocked sites](blocked-sites.md) | Sites no agent or MCP client can read or act on, enforced in the browser where the agent cannot change it |
| [Skills](skills.md) | How an instruction is routed to a playbook, and how to write your own |
